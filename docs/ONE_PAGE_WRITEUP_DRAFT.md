# SignalBridge — evidence-led AI & robotics outreach (draft; revise before submission)

**Problem & scope.** Build a small, reliable workflow for finding relevant AI/robotics individuals, reviewing the evidence behind each match, drafting respectful personalized messages, approving them explicitly, tracking sends and replies, and preventing duplicate outreach. This sprint prioritizes a reproducible local workflow over broad, high-volume prospecting.

**Approach.** A single-user FastAPI application uses SQLite to store campaigns, profiles, message drafts, recipient locks and audit events. Prospect discovery has three paths: a clearly fictional synthetic catalog for offline demonstrations, manual evidence-backed import, and an optional official X recent-post author search (requiring appropriate user-context API access). A transparent keyword score exposes its signals rather than presenting an opaque probability. Default drafting is a deterministic evidence-grounded template, with an optional OpenAI-backed provider that must be explicitly enabled. An operator may edit and approve the text before any send. Mock transport and X API transport are separate and labeled, and real outbound messages require consent, a numeric test recipient ID, and a configured allowlist. Timeout outcomes become `uncertain`; they are never automatically retried.

**What works vs what remains.** The local discovery → draft → approval → mock delivery → duplicate prevention → simulated reply flow is implemented and covered by offline API tests. The X send/read adapter follows documented official endpoints but has **not been validated with live X credentials or paid access**, and the app does not implement a browser-based OAuth sign-in. This means it is not a production outreach system today. The sample names, posts and mock replies are not real.

**Trade-offs.** FastAPI + SQLite + framework-free frontend keeps installation and maintenance light; PostgreSQL, multi-user login, encrypted token management, authenticated OAuth consent, webhooks and stronger semantic/recency ranking would be needed for an employer-run service. Evidence quality matters more than list size. Idempotency and explicit approvals are deliberate non-negotiable safeguards.

**Cost and AI disclosure.** With template mode, synthetic discovery and mock delivery, X and LLM API spend is **$0**. Real usage requires checking actual X credit prices, scopes, rate limits and the model provider's token costs in the operator's own accounts; no credit purchase has been made for this build.
